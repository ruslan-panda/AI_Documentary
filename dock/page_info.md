# Описание структуры и функционала страницы

### 1. Структура и цвета страницы (`style.css` и `index.html`)
* **Общий вид:** Страница поддерживает вертикальную прокрутку (скролл) вверх и вниз.
* **Шапка (`header`) и Подвал (`footer`):** 
  * Закрашены в единый контрастный темно-графитовый цвет (`#1e2229`).
  * Переход от шапки и подвала к основному светлому фону страницы (`#f4f5f7`) выполнен резко, без лишних разделительных полос и линий.
  * Текст внутри выровнен по центру.

### 2. Главные блоки (Карточки)
* **Расположение:** На странице размещено ровно **6 больших прямоугольных блоков**, выстроенных сеткой по 2 штуки в строке.
* **Эффект при наведении (`hover`):** При наведении курсора мыши прямоугольник плавно выдвигается вперед (поднимается вверх на 8 пикселей и слегка увеличивается), а под ним появляется мягкая объемная тень.
* **Внутреннее устройство каждого блока:**
  * **Левая часть:** Большое прямоугольное поле-заглушка с пунктирной рамкой для будущей фотографии (`[ ФОТО СЛЕВА ]`).
  * **Правая часть:** Блок с текстом, который включает в себя крупный заголовок, подробное описание темы и текстовую подсказку-призыв к действию.

### 3. Интерактивные всплывающие окна (Модальные окна)
* **Технология:** Работают на встроенных средствах браузера без использования JavaScript (используется нативный HTML-атрибут `popover`).
* **Как открываются:** При клике на любой из 6 блоков поверх страницы плавно появляется отдельное графическое окно.
* **Анимация появления:** Окно и задний фон страницы (`backdrop`) плавно проявляются и масштабируются без резких рывков.
* **Содержимое каждого всплывающего окна:**
  * Заголовок и поясняющий текст.
  * Блок с примером **реального кода на Python** (оформлен через теги `<pre><code>`, благодаря чему сохраняются все отступы и форматирование кода).
  * Кнопка «Закрыть окошко» для возврата к основному просмотру.
