* **Факультет:** Факультет компьютерных наук (ФКН)
* **Направление:** Математика и компьютерные науки (МКН)
* **Группа:** 15 и 16 группа

## Архитектура сайта (Одностраничник / Landing Page)
Проект реализуется в виде одной функциональной страницы. Все методы машинного обучения выводятся динамически.

* **URL Главной страницы:** `/`
* **Шаблон:** `templates/index.html`

## Техническое взаимодействие Backend (Руслан) и ИИ (Дмитрий):
1. Дмитрий реализует методы машинного обучения (ML) и генерирует данные для визуализации (массивы точек, графики, метрики обучения).
2. Руслан через пакет `/utils/` забирает эти данные, при необходимости кэширует/сохраняет их в СУБД PostgreSQL.
3. Функция `home_page` в `core/views.py` передает эти данные в шаблон `index.html`.

## Структура блоков на главной странице:
1. **Шапка (Header):** Название проекта, ссылки-якоря для плавной прокрутки к разным методам ML.
3. **Каталог методов машинного обучения:** Динамический список, где для каждого метода есть:
   - Текстовое описание алгоритма.
   - Зона визуализации.
   - Интерактивный блок/кнопка для отображения примера исходного кода Python.
4. **Подвал (Footer):** Состав команды.
